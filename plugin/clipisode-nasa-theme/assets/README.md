# Mission Control vector asset kit

Original SVG artwork supplied with the NASA · Mission Control Clipisode theme. The art uses a spaceflight-inspired visual language but does not reproduce NASA's official insignia.

## Rocket marks

- `rocket-multistage.svg` — tall launch vehicle
- `rocket-capsule.svg` — retro capsule rocket
- `rocket-shuttle.svg` — delta-wing orbiter
- `rocket-swoosh.svg` — ascending rocket and orbital route
- `rocket-patch.svg` — circular mission mark
- `rocket-toy.svg` — rounded playful rocket

## Scene and status artwork

- `earth-limb.svg`
- `moon.svg`
- `ringed-planet.svg`
- `astronaut.svg`
- `satellite.svg`
- `orbital-route.svg`
- `mission-complete.svg`
- `signal-acquired.svg`
- `contact-sheet.svg`

All files use view boxes and vector paths, so colors can be changed in a vector editor or directly in the SVG source. Matching geometry is drawn inline by `renderer.js` to keep video preview and export self-contained.
